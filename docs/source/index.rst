Welcome to RobeRT-py documentation!
===================================

**RobeRT-py** is a python library to interact with the `RobeRT Middleware <https://github.com/JuanSobalvarro/robert-middleware>`_, offering a **simple** and main class client. This is my thesis work so I can graduate as a Cybernetic Electronics Engineer ^^. I hope you find it at least funny to use, you can do very interesting integrations since you are using python to communicate with the robot.

.. note::
    This project is only for the usage of RobeRT Middleware, so if you are trying to use this project you need to use it as a whole, go check robert-middleware.
